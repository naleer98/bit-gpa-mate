# BIT GPA Mate — Flutter-inspired Final UI

This final project keeps all existing functionality and adds a more polished mobile app experience.

## UI updates

- Material/Flutter-inspired University of Moratuwa app bar
- Improved logo presentation and typography
- Compact mobile header without status-bar crowding
- Floating rounded mobile bottom navigation
- Clear active-tab state and touch feedback
- Softer Material-style cards, shadows, buttons, and spacing
- Light and dark themes retained

## Functionality retained

- SGPA, LGPA, CGPA calculations
- Level 1 Diploma eligibility celebration
- Level 2 Higher Diploma tracking
- Level 3 Degree and class tracking
- Grade/marks input modes
- Level 3 elective selection
- Offline PWA and local storage
- Android source project
- Signed APK/AAB GitHub workflow
