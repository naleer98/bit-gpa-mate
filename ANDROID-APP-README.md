# BIT GPA Mate Native Android App

This repository contains both the GitHub Pages PWA and a native Android wrapper in `android/`.

The Android app embeds the calculator locally using WebViewAssetLoader, so it works offline and keeps GPA data on the device. The native launch experience includes the developer credit and tagline requested for the mobile loading view.

Build output: `android/app/build/outputs/apk/debug/app-debug.apk`

GitHub Actions workflow: `.github/workflows/build-android-apk.yml`
